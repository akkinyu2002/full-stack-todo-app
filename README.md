# Full-Stack Todo App

A simple full-stack Todo application built to practice frontend development, REST APIs, database persistence, and API testing.

## Overview

This project allows users to create, complete, and delete tasks. Todo data is stored in a database, so tasks remain available after refreshing the application.

The project was built with a focus on keeping the interface simple, clean, and easy to use.

## Features

- Add new tasks
- View saved tasks
- Mark tasks as completed
- Delete tasks permanently
- Display total tasks
- Display completed task count
- Persistent database storage
- REST API
- API testing with Postman
- Responsive interface
